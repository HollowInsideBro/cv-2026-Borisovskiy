# Лабораторная 1: Среда, репозиторий и первый взгляд на данные

## 1. Задача

Изучить изображения и разметку своего варианта, проверить чтение и базовые преобразования изображений через OpenCV, собрать сводку по файлам.

## 2. Как запустить

Откройте `solution.ipynb` в Colab или Kaggle, проверьте `VARIANT = 3` в первой ячейке и выполните Run All. Зависимости указаны в `requirements.txt`. Ноутбук запускался локально; результаты сохранены в `results/`.

При проверке данные скрипта курса архив прошёл опубликованную проверку SHA-256, но проверка внутреннего digest распакованных файлов не совпала. Ноутбук показывает это и использует архив только после проверки SHA-256, CRC ZIP и состава варианта.

## 3. Данные

Вариант 03: `British_Shorthair`, `Russian_Blue`, `beagle`, `leonberger`. В наборе 806 изображений, 404 XML-бокса и 806 trimap-масок.

## 5. Выводы

- Породы представлены почти поровну: по 202 изображения у British Shorthair, Russian Blue и beagle, 200 у leonberger.
- Все 806 файлов — JPEG в режиме RGB; файлов с несовпадающим форматом или режимом нет.
- XML-бокс есть у 404 из 806 изображений (50,1%), поэтому боксы покрывают только часть набора.
- Медианный размер кадра — 500×375 px; преобразование к 224×224 без сохранения пропорций растягивает изображение.
